UFR STGI · troisième année

Chaque séance part d'une entreprise, d'un fichier et d'une question. On cherche d'abord à la
main ce qui se passe dans les données, puis on le refait en Python, dans Jupyter, sur son
propre ordinateur.

## Avant la première séance pratique

Installez Jupyter en suivant **[installer-jupyter.pdf](installer-jupyter.pdf)** (macOS, Linux,
Windows). Tout s'installe dans un dossier `ia-elc2`, dans un environnement virtuel : rien n'est
installé dans le Python de votre système.

## Récupérer les fichiers d'une séance

Ouvrez le dossier de la séance et téléchargez l'archive `seanceN-etudiants.zip` (bouton de
téléchargement, en haut à droite du fichier).

- **Séance 1** : l'archive contient le dossier `ia-elc2` lui-même. Suivez le guide d'installation.
- **Séances suivantes** : placez les fichiers de l'archive dans votre dossier `ia-elc2`.

Ou, si vous connaissez git :

```bash
git clone https://github.com/josephazar/ELC2-Introduction-IA-2026.git
```
